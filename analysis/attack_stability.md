# Selected algorithmic bounds and attack events

Generated by analysis/attack_stability.py. Source-checked by an agent on 2026-10-09; not independently verified by a human. This is a selected, incomplete history, not a security forecast.

## Method

Numerical tracks evaluate selected leading-term formulas at a declared reference size. They omit polynomial/lower-order factors and do not share a calibrated operation unit across algorithms. Their differences are changes in an index, not observed security bits lost. The inverse view finds the size giving index 128, not a recommended cryptographic parameter.

Each series uses currently supported analyses, dated when the quoted analysis became public. Earlier algorithm dates and corrected claims are retained in notes. This is not a reconstruction of historical beliefs. Series eligibility is explicit and sourced; practicality is not a Boolean filter. The minimum is taken only over these selected bounds, independently for each view. No count of exponent changes or security-stability duration is inferred.

Lattice indices describe an SVP oracle, not full ML-KEM attacks. Decoding indices maximize over code rates separately for each algorithm, not a single fixed-rate code. MQ bounds have explicit algebraic/randomization assumptions. See each track.

Qualitative events cover finite-field reassessments and SIDH. A missing/inapplicable numerical model means not estimated, never infinite size or zero remaining security. No placeholder compute is used.

## ECDLP, prime-field curves

Discrete logarithm in a prime-order subgroup of an elliptic curve over a prime field, using generic collision attacks and the universally available negation map.

Selected classical collision-cost models, not an exhaustive attack history. The constant-factor negation saving changes the modeled cost by 0.5 bits while the square-root exponent stays unchanged. Additional automorphisms, weak curve families, parallel hardware and implementation costs require separate analyses. The group-order parameter must not be confused with field size: for example, Curve25519 has a roughly 252-bit prime-order subgroup.

Track assumptions: An idealized random walk and birthday-collision calculation give k sqrt(r) for subgroup order r. Per-step costs, cycle handling, coordination and memory are omitted. Both entries use the same model; a flat selected envelope is not evidence that all cryptanalysis stopped.

Reference: P-256-sized group. A fixed illustrative group-order size. The plotted birthday-model index is not a complete concrete security estimate for every 256-bit curve.

## Lattices (selected classical SVP sieve bounds)

Heuristic classical sieving for Euclidean SVP in dimension n. The selected series compares leading coefficients in 2^(c n + o(n)); this is an SVP-subroutine index, not a history of full ML-KEM attacks or practical runtimes.

The selected series starts at the checked 2008 Nguyen-Vidick publication, not the invention of lattice cryptography. Context records describe other tasks, guarantees or lower-order improvements. Dates refer to the public appearance of the quoted analysis where established, with uncertainty noted. This is a selected history, not a completeness claim for all attacks or quantum algorithms. A flat leading coefficient does not mean unchanged finite-size attack cost. The separate frontier track compares actual sieve dimension 171 with refined target sieve dimension 375; those dimensions cannot be interchanged with this coarse 406-dimensional oracle.

Track assumptions: Selected sieve analyses use heuristic distribution assumptions and exponential memory. Lower-order terms, preprocessing, repeated oracle calls, reduction quality, hardware and memory-access costs are omitted. Memory requirements vary by algorithm and variant. Worst-case enumeration bounds are not mixed with heuristic sieve bounds.

Reference: SVP oracle dimension 406. Illustrative dimension from the coarse primal core-SVP row of Kyber round-3 Table 4. Its blocksize is 406; the separate refined model uses blocksize 413 and sieve dimension 375. Holding this oracle dimension fixed does not hold a full historical LWE attack model fixed. An inverse index of 128 is not a scheme parameter recommendation.

## Syndrome decoding (binary, full-distance exponent)

Selected classical upper bounds for decoding random binary linear codes at full Gilbert-Varshamov distance: for each algorithm, maximize its optimized time exponent over code rate R = k/n, with relative error weight H_2^{-1}(1-R). The coefficient c describes time 2^(c n + o(n)). The maximizing rate can change between algorithms; this is not a fixed-rate or fixed-code-instance comparison.

The numeric series is deliberately limited to four sourced analyses from 2012 onward. It is not a complete history or a certification of the best attack as of 2026; omitted work and gaps between selected entries are not evidence of stability. Earlier ball-collision and representation work is retained as context without retrospectively dating coefficients from later comparison tables. Each year is the first public year of the quoted analysis rather than automatically the proceedings year; algorithm_year records an older algorithm when applicable. The series includes only bounds that remain supported by the cited analyses, under their assumptions. It does not reconstruct what researchers believed at every historical date: the original Both-May 0.0885 claim is excluded, and the corrected 0.0951 analysis enters in 2022. Different papers round numerical optima differently, so differences in the last reported decimal are not precise measurements. All entries remain verified:false pending the separate human review.

Track assumptions: Binary random linear codes; classical computation; full GV distance, not half-distance decoding; numerical optimization over algorithm parameters and then maximization over rate. The quoted asymptotic analyses and their distributional/list-size assumptions are accepted as stated. Polynomial factors, lower-order exponents, finite-size costs, and memory constraints are omitted. Exponential memory is allowed. Multiplying the rounded coefficient by n gives an index, not a calibrated operation count.

Reference: n = 1346; worst-over-rate full-distance index. 1346 is 128/0.0951 rounded to the nearest integer, so the selected corrected endpoint has c*n = 128.0046. This is an arbitrary normalization of an asymptotic exponent, not a claim of 128-bit security for a concrete code or deployed scheme. Each bound can attain its maximum at a different rate; no common rate, dimension, or error weight is fixed by this reference.

## Factoring (RSA)

Factoring a general balanced semiprime N = pq, with equally sized prime factors and no special algebraic form.

Selected classical asymptotic bounds beginning with the 1982 quadratic-sieve analysis; earlier methods remain outside this deliberately limited curve. L_N[a,c] means exp((c+o(1))(ln N)^a(ln ln N)^(1-a)); the plotted index drops o(1), polynomial factors and constants outside this expression. Coppersmith’s multiple-polynomial NFS bound is included under the same asymptotic criterion as other tracks. This selection omits intermediate algorithms and does not reconstruct the complete historical best attack. A small difference in the index is not a demonstrated speedup at a real RSA size.

Track assumptions: Rho uses a random-walk heuristic; sieve bounds assume suitable smoothness and relation behavior. Costs are represented only by their displayed leading expressions. Memory, preprocessing, parallelism, lower-order terms and measured implementations are not equalized.

Reference: 3072-bit modulus. A familiar RSA size used only as a fixed reference. Leading asymptotic expressions are not calibrated security estimates or parameter recommendations.

## Multivariate quadratic systems over GF(2)

Finding a solution, or deciding that none exists, for n quadratic equations in n variables over GF(2). Random-system algebraic estimates and general-input randomized bounds are distinguished in each entry.

A selected timeline of sourced analyses, beginning in 2004, not a complete historical best-known envelope. Earlier XL and hybrid methods matter: the original FXL exponent was later corrected, and the corrected value is dated to the checked analysis version rather than backdated to the algorithm’s proposal. Lower-order factors and memory can dominate at the reference size. These generic-system estimates do not establish the security of a structured multivariate signature scheme.

Track assumptions: The plotted costs are 2^(c n) after dropping polynomial and lower-order terms. Conditional random-system algebraic estimates and randomized worst-case bounds share the same square Boolean target, but have different guarantees; their minimum is only an envelope of selected stated models. Date fields use the earliest checked public analysis or explicitly identified checked revision; undocumented earlier circulation is not inferred.

Reference: n = 184, m = n. An illustrative square Boolean system. The selected 0.6943 leading exponent gives 127.7512 at this size, approximately 128; this is neither a standardized parameter set nor a concrete security recommendation.
